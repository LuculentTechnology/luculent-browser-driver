Luculent Browser Driver for AI Agents

Decide what connected AI agents may do in this browser. Changes save instantly and apply to every agent and API key.

KillswitchStops every agent, detaches every tab and refuses all commands until you resume. Shortcut: Alt+Shift+K.

Which tabs

Agents can use"Granted tabs" means only tabs you allow below or in the popup, plus tabs the agent opens itself.
Incognito tabsOff by default. Chrome also requires "Allow in Incognito" on the extension.

What agents may do

Read-only modeAgents can open pages, scroll and read, but cannot click, type, upload or run JavaScript.
Passwords"Block" hides password field values from agents and stops them typing into password fields.
Submit login or payment formsAlso covers typing into card number / CVC fields.
Run JavaScript in pagesLets an agent run any code in a page, which can read anything on it, including password fields.
CookiesRead or change cookies (sign-in sessions live in cookies).
Site storageRead or change localStorage / sessionStorage.
Upload local filesAttach files from your computer to web forms. "Ask me" shows each file first.
DownloadsLet pages an agent drives save files to your computer.
Browser-internal pageschrome://, other extensions, DevTools. This extension's own pages are always off limits.
Local files (file://)
Raw DevTools protocolFor advanced API keys with the cdp scope.
Background (headless) Chrome

What is this banner? Chrome sometimes shows a bar that says this extension "is debugging this browser." Chrome shows that bar for any extension that can control a window. It cannot be hidden. It only means an AI agent is allowed to control that window — not that your computer is being hacked, and not that anything is being sent off your machine. To stop it, press the killswitch in the popup (or Alt+Shift+K), or click Cancel on the banner.
